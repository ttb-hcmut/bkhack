## Quarkdown isn't a general-purpose typesetting language

No dedicated styling system. CSS styling, as we're adopting right now, is a hack over Revealjs.

> As the styling system is fragile, you are not encouraged to make radical stylistic changes.

## Quarkdown isn't a general-purpose presentation system

Can add page numbering, but can't control numbering order

> For example, you can't skip numbering for title page

Slide direction is based on device width (e.g. browser window size i.e. mobile size or desktop size).

> In most cases you will show / read slide on your computer, so direction is horizontal. But slides in Bach Khoa are vertical.

No custom transitions. No morphs. No script-based interactions (unless you're willing to embed HTML).
